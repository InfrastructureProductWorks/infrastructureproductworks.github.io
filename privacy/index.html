PRIVACY

Collect less. Expose less.

This portfolio presents product information without requiring a visitor account. Selected demo areas require email verification as explained below. The optional portfolio inquiry form asks for your name, email address, product, request type, summary and description. You may also provide reproduction steps and browser or environment details. Inquiry fields are submitted to a hosted processing endpoint; this is separate from simply browsing the website. Please provide only what is needed to explain your portfolio question. Do not include credentials, tokens, private keys, customer records or sensitive infrastructure details. The inquiry channel is not production support and does not authorize operational work.

Website delivery, security and measurement

Website notice updated October 30, 2026. IPW uses GitHub Pages for this website and Cloudflare for proxied delivery, HTTPS, network security and selected demo access. Those services process request information such as IP address, timestamp, requested address and browser information to deliver and protect the site. Security challenges may use cookies. Access can be limited by security or geographic rules; removing the demo login requirement from marketing pages does not remove those protections.

Cloudflare Web Analytics is enabled for aggregate website usage and performance measurement. Cloudflare states that this analytics service does not use cookies or local storage to collect usage metrics and does not track individuals over time through fingerprinting. This describes Web Analytics, not all Cloudflare security or authentication processing. See Cloudflare Web Analytics and Cloudflare privacy information.

The October 30 configuration review found no third-party tools configured in Cloudflare Zaraz. That is a dated configuration observation, not a guarantee about every script or external product. Demo email verification and inquiry processing do not authorize optional advertising, marketing reuse or AI training. New optional tracking requires a separate purpose and privacy review, and consent controls where required, before activation.

Demo email verification

Marketing pages and user guides do not require the demo email code. The Northstar Signal, Guard, Console and Assurance demo areas, and the Assurance Portal, use Cloudflare Access email one-time codes. Cloudflare processes the email address you submit to send the code and authenticate access, and uses authorization cookies to maintain the authenticated session. Authorized IPW account operators can review access records containing identity and connection information for access administration and security.

The configured demo session is 24 hours. Session duration is not the retention period for authentication, security or provider records. Those records follow the applicable service plan and provider arrangements; IPW has not established a single verified deletion period across these services. Contact office@InfrastructureProductWorks.com about access, correction, retention or deletion before submitting information if you need a specific handling commitment. We will assess requests against the records and provider controls available; we do not promise immediate deletion from provider backups or security records.

An email code verifies access to a mailbox for the demo gate. It does not verify employment, organization authority, acceptance of contractual terms, marketing consent or permission to operate infrastructure. Use fictional information inside demonstrations. The Forge and Storefront previews launch on separate Render hosts; the website's Cloudflare Access rule does not protect those hostnames. Publicly published demo source and synthetic assets remain disclosed material, and the email gate is not a confidentiality guarantee.

Optional inquiries

Inquiry notice version: inquiry-2026-10-29. The form asks you to request processing for inquiry review and response. Leaving that choice unchecked does not prevent browsing this portfolio. It does not enroll you in marketing or grant permission to operate your infrastructure.

When inquiry intake is enabled, your submitted fields are sent to a receiver hosted by Render and recorded in a private GitHub issue for inquiry handling. Authorized operators with access to that issue can review the information and respond using the contact address you supply. The record includes the inquiry purpose, notice version and server receipt time. This records the submitted request; it does not verify the sender's identity.

Hosting, network security and service providers may process request metadata such as IP address, timestamp and browser information under their own service arrangements. The inquiry processing choice does not control essential network or security processing and does not authorize optional analytics, advertising or AI training.

For questions about an inquiry record, retention, access, correction or deletion, contact office@InfrastructureProductWorks.com. Include your inquiry reference if available, without resending sensitive material. We may need to verify that a request concerns your information; some records may need to be retained for applicable legal or security reasons. Please do not send identity documents unless a secure method has been arranged.

Installed applications and customer-hosted products require their own scope-specific data-handling review; this website notice does not establish a processing agreement for those products.

IaaP Guard data boundaries

Guard is designed around customer-controlled infrastructure workflows. Customers should not place credentials, personal data or unrelated sensitive information into support requests or public repositories. Product-specific data handling and permissions should be evaluated against the installed release and its documented configuration.
