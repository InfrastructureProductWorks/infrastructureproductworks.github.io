SYNTHETIC ONLY. This browser demo combines three bounded views: a Sentry profile preview based on accepted predeployment contracts and the Gate 3 vertical slice, the accepted Gate 5 runtime proof, and the accepted Gate 6 protected-data custody proof. No live identities, approvals, credentials, connectors, infrastructure, protected data, production authorization or durable evidence writes are used.
How to use this demo
  1. Start with Sentry: compare Policy Violation with Bounded Correction.
  2. In Shield, inspect Valid Authority, then try each denial and rollback scenario.
  3. Read what happened, why, and the next step on each independent request card.
  4. Use Export requests for Portal for all three cards, or Export Record Preview for the active Shield scenario. Import the file in the Portal to follow those same decisions.
  5. Open Protected Data Custody and compare authorized access with broadened delegation and audit suppression.
