IAAP GUARD DOCUMENTATION

Customer-controlled validation.

IaaP Guard adds deterministic infrastructure validation to GitHub pull-request workflows while preserving the boundary between validation, approval and deployment authority.

PRODUCT CONTRACT

What Guard does, and what it does not do.

Input

Infrastructure change context and evidence required by the applicable validation contract.

Evaluation

Versioned deterministic rules evaluate architecture, policy, network, security and evidence conditions.

Outcome

PASS, WARNING or FAIL results provide reviewable evidence within the delivery workflow.

Authority boundary

A Guard result does not independently approve, apply or provision production infrastructure.

Customer control

Repository owners retain branch protections, approvals, credentials and deployment controls.

Portability

The product direction favors customer-controlled operation and portability rather than hidden operational authority.
