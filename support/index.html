PORTFOLIO INQUIRY

Ask about the portfolio without treating it like
an operational service desk.

This page is for questions about the public portfolio, documentation, public-demo behavior and repository evidence. It is not production support, implementation support, procurement intake, consulting intake or an operational service desk.

SAFE INQUIRY BOUNDARY

Do not submit sensitive material.

Do not include credentials, tokens, private keys, exploit details, proprietary infrastructure, taxpayer data, protected data, customer data or other sensitive material. Security concerns should follow the security reporting guidance.
