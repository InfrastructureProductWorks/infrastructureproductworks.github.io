CUSTOMER SUPPORT

Support without exposing your infrastructure.

For IaaP Guard Public Beta questions, installation issues, deterministic validation behavior or documentation problems, use the public Guard issue tracker when the report contains no sensitive information.

Guard issue trackerRead Guard docs

Do not post secrets or customer data.

Never include credentials, tokens, private keys, sensitive infrastructure details, proprietary configuration or personal data in a public support request. Security-sensitive reports should follow the security guidance rather than a public issue.
